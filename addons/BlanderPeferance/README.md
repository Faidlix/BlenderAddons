# Blander Peferance

保留使用者目前的 Blender 介面預設值，並提供繁體中文／原語系快速切換。

## 行為

- 啟用外掛時，自動關閉 Blender 的「讀取 UI」預設值。
- 每次載入檔案後，再把下一次開啟檔案的預設值恢復為關閉。
- 若某個檔案確實需要自己的介面，仍可在開啟檔案視窗手動勾選「讀取 UI」；該次載入不受阻止。
- 最上方工作區分頁前提供地球按鈕；第一次按切換繁體中文，再按一次恢復原本語系。
- 同一個切換功能也可在「偏好設定 > 外掛 > Blander Peferance」操作。
- 切換繁中時啟用介面、提示、報告與新資料名稱翻譯，並補充 Auto-Rig Pro 等常見外掛詞彙。
- 不修改模型、材質或場景。

Blender 只能翻譯官方語系檔或外掛字典中存在的文字。完全沒有提供翻譯資料的第三方外掛，部分專有文字仍可能維持原文。

## 手動確認

在「編輯 > 偏好設定 > 儲存與載入」中，可確認「載入 UI」維持未勾選。

## Blender 5.2 偏好設定備份

`preferences_backup/Blender-5.2-userpref.blend` 是建立此外掛時的 Blender 5.2 偏好設定備份。
還原前請先備份自己現有的 `userpref.blend`，並只在相同 Blender 版本中使用。
