- 切換／再次點選 Action 時，只依目前指定骨架 Slot 的實際 Key／取樣資料更新時間軸並補齊頭尾。其他 Slot 的較長動畫不再拉長目前骨架的範圍，其他 Slot 的曲線維持原樣。

### 1.5.0 — 一起調整選取 Keys

Pose Mode 選取骨頭及 Dope Sheet／Graph Editor 的變換 Key，右鍵選「一起調整選取 Keys」，或用側邊欄按鈕啟用。G／R／S 與原生操作軸每次確認後立即套用。拖曳時預覽目前影格，確認後顯示處理進度；Esc 取消當次操作，Ctrl+Z 復原，模式可持續改選骨頭與 Key。

- 整體轉向連同路徑：沿目前影格的中心，把動作與移動路徑一起轉向。
- 整體轉向保留路徑：指定主控骨，以它在各影格的位置為中心；旋轉／縮放保留該位置路徑，G 位移仍套用同一偏移。
- 局部姿勢：沿用目前軸向和中心點。共同／活動／個別中心隨各影格重新計算，3D 游標固定。
- 選取 Key 指定各骨頭的目標影格，必要軸一起換算；只在同一批選取影格補必要 Key，不逐格烘焙，不改其他 Slot。
- 保留既有點的影格、插值及控制柄類型，更新其值與控制柄；新增點使用 Bezier／Auto Clamped。一般空間旋轉無法保證中間曲線完全等同逐格變換；新增通道依 Blender 曲線外插影響原本沒有 Key 的時間。
- IK Target／Pole 漏選時，提示自動加入或維持原選取；確認後重新開始操作，自動加入只用本次選取影格集合。
- Cycles 保留。Noise 等其他修飾器、取樣／锁定／停用曲線、Driver、其他作用中骨骼約束、混用旋轉通道、NLA 疊加或無法表達的剪切取消當次調整，不自動烘焙。骨架物件本身及其父物件動畫不在本工具範圍內。
- Action／骨架／工作區切換、離開 Pose Mode、載入檔案或停用外掛時结束模式。模式中暫停原生 Auto Key 避免新增未選取的目前影格，操作完成／取消後恢復原設定。

### 1.5.1

- 啟用一起調整後，3D View 上方中央顯示浮動工具列；「一起調整：開／關」可暫停套用 Key，關閉時工具列保留並恢復一般骨骼操作。旁邊直接切換三種模式；保留路徑模式有主控骨設定。× 同時關閉工具列與一起調整，保留已完成修改。
- 修正父子骨骼 Key 時間不同時的重複變換：已選父骨在子骨影格也參與姿勢換算，但只在父骨原本選取影格寫 Key。裙子在 45 有 Key、Hips 在 45 沒有 Key 時，不再把父骨的轉向補成裙子的額外位移／旋轉。
- 保留 Quaternion 原始幅度，避免正規化造成不必要的子骨 Key 改寫；忽略縮放浮點誤差。
- 既有錯誤結果不自動覆寫，請從原始 Action 重新複製再轉向。

### 1.5.2

- 工具列改名「動作一起調整」；停用時只保留開關與「關閉」，啟用才顯示模式選項。
- 保留路徑模式直接顯示主控骨名稱；點擊欄位搜尋並選取骨頭，立即生效，不再開啟設定／確認彈窗。
- 「關閉」同時關閉工具列與模式，保留已完成的修改。

- 移除局部姿勢獨立選項；保留連同路徑／保留路徑，調整部位依選取骨骼決定。
- 滑鼠停在兩種模式或主控骨欄位時，顯示功能說明。

### 1.6.0

- 改名「多影格同步調整」。第一行主按鈕與關閉；第二行路徑選項合計與主按鈕齊寬；保留路徑的主控骨獨立第三行，同樣齊寬。停用時只保留第一行。
- 原生旋轉期間，Viewport 顯示起始／目前方向、弧線與相對方向角度；以目前骨骼姿勢矩陣計算，確認或取消旋轉後隱藏。
- Pose 模式切換 Action 保留啟用／暫停狀態，丟棄舊操作暫存，重新讀取目前選取的骨骼與 Key。寫回期間禁止切換；外部切換會取消尚未完成的寫回。
- 可同時處理已有的 Euler、Quaternion、Axis Angle 通道：目前旋轉模式為姿勢來源，再寫回其他旋轉表示。Quaternion／Axis Angle 下的備用 Euler 通道採 XYZ。保留未選取的 Key 與貝茲插值；必要軸只補選取影格，不做全影格烘焙。
- 刪除後選上一個 Action，第一個則選下一個，清單為空才清除選取；保留清單項目與鄰近位置。
- 複製彈窗縮窄，只保留「複製到」骨架選單與複製／取消；新 Action 直接載入清單選取，供直接改名。

### 1.6.1

- 複製 Action 彈窗移除上方標題；只顯示「複製 Action 到：」骨架選單與複製／取消按鈕。
- 未選取 IK 控制骨提示改成兩個立即確認按鈕，初始不預選。點「自動加入」或「維持原選取」即採用並關閉選單，不再額外確認；Esc／點外側關閉不會寫入選擇。

### 1.6.2

- IK 選擇改成固定確認面板，移動游標或 Enter 不會關閉／選第一項。仍無預選，只有新的滑鼠按下與同按鈕放開才採用選項。
- 開啟面板的滑鼠操作必須先放開；該次放開即使落在按鈕上也不會確認。Esc 或新的外側點擊可關閉且不寫入選擇。
- 多個 IK 控制骨可用滾輪查看；離開目前骨架／Action／工作區時清理面板。
