# Blender 外掛介面設計規範

- 選項選擇預設使用按鈕，不使用下拉選單；只有使用者明確指定時才保留下拉選單。
- 按鈕預設顯示文字。只有使用者特別要求「不要文字」時，才改為純圖示按鈕。
- 操作按鈕的文字不得因側邊欄變窄而消失或被截成難以辨識的省略號；應先讓操作列獨立換行、保留足夠寬度，再考慮縮短非操作資訊（如檔名）。Tooltip 不能取代可見按鈕文字。
- 同一組互斥選項以並排按鈕呈現，清楚標示目前選取的項目。
- 表格欄寬以標題之間的垂直分隔線直接調整，標題與下方資料列必須同步；不要用比例數值欄或滑桿取代。
- 分隔線操作預期為按住滑鼠左鍵、左右拖移、放開即完成，不是點一下進入調整、移動後再點一下。
- 拖曳某欄分隔線應只改變對應的相鄰欄位，不連帶改變更右側欄位；拖曳靈敏度須足以細緻調整。
- 相鄰的可調欄位各自有分隔線與獨立寬度；標題需對齊該欄實際控制項，不能因拖曳旁邊欄位而偏移。
- 同一欄的狀態按鈕應以最長狀態文字設定固定寬度，避免「啟用／未啟用」切換時造成欄位跳動。
- Bone Remap 的 IK 設定區由「設定 IK」按鈕在外掛側邊欄內展開；不得另開顯示其他面板的 Properties 視窗。關閉時還原進入前選取的骨架與模式。
- 目標動畫播放清單放在批次重定向執行按鈕之後；播放選定 Action 時，時間軸 Start／End 對齊該 Action 的影格範圍。
